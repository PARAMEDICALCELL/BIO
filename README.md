# Biologie in real life

Site statique (HTML, CSS, JavaScript) avec modèles 3D Three.js.

## Structure
- `index.html` : structure et SEO de la page
- `css/style.css` : styles, thèmes clair et sombre
- `assets/dna-bg.svg` : image d'ADN utilisée en arrière-plan
- `js/script.js` : cours, ressources, WhatsApp et modèles 3D

## Publier sur GitHub Pages
1. Créez un dépôt et envoyez ces fichiers à la racine.
2. Dans Settings > Pages, choisissez la branche `main` et le dossier `/ (root)`.
3. Le site sera disponible à l'adresse indiquée par GitHub.

## Modifier le contenu
- Cours, fichiers et numéro WhatsApp : haut de `js/script.js`.
- Textes et tarifs : `index.html`.
